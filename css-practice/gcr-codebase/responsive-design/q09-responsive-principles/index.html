Responsive Css

Three Responsive Principles

Fluid layouts

Use flexible tracks such as 1fr.

grid-template-columns: 1fr 2fr;

Flexible media

Let media shrink inside its container.

img { max-width: 100%; }

Breakpoints

Change layout when content needs it.

@media (max-width: 600px)
